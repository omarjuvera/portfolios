A community problem, and a practical lesson

The project grew from a multilingual congregation's need to follow the same services. I built it independently and successfully tested the workflow. The church liked the result, but ongoing AWS costs made adoption impractical. It chose Zoom's native translation instead.

That experience made cost part of the design problem. I am sharing the recovered source so other developers can study the approach, while planning a separate Zoom API project.

What you can inspect and reuse

The repository includes recovered transcription and translation/speech handlers, a vocabulary dictionary, an artifact manifest and documentation of the prototype's limits. The extraction stage is documented in the original report; its standalone source was not present in this archive.
